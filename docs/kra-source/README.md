# Official KRA source documents

Place the current KRA-issued OSCU integration specification, API schemas, onboarding instructions, and certification test pack in this directory (or a controlled private artifact store if redistribution is prohibited).

For each document record:
- exact title and filename
- issuing KRA department/contact or official source
- version/revision and issue date
- date received
- SHA-256 checksum
- confidentiality/redistribution restrictions

Do not commit confidential KRA material unless its terms permit it. If the document cannot be stored in this repository, keep a sanitized version register and provide the document securely to the implementation team.

**No protocol endpoint or payload schema is assumed by this repository until verified against these official documents.**
