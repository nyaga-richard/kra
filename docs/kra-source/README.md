## Important document-handling restriction

The publicly linked OSCU Specification v2.0 PDF contains a confidentiality disclaimer restricting reproduction, dissemination, copying, disclosure, modification, distribution, and publication without KRA's express written permission. Do not commit or redistribute that PDF or extracted proprietary content in this public repository. Obtain the authorized integrator copy through the KRA taxpayer portal/onboarding process and follow its terms. Store sensitive documents in an access-controlled location.

## Version register

Record the following in an internal, access-controlled register for each authorized document:
- exact title and filename
- issuing KRA department/contact or official source
- version/revision and issue date
- date received
- SHA-256 checksum
- confidentiality/redistribution restrictions
- superseded-by version, if any
